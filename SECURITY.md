# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report them privately by opening a security advisory at:

https://github.com/Nex-Devz/YuKumo/security/advisories/new

Or reach out to the maintainers via email.

We aim to respond to reports within 48 hours. Once a fix is ready, a
coordinated disclosure will be published as part of a patch release.
